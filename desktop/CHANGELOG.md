# Changelog

## Unreleased

- 外部服务的写操作改为先自动审查：常规操作直接放行，只有涉及金钱、删除、权限、对外发送等高风险操作才弹审批，卡片附审查理由；工具页的审批方式新增「智能」档。以前在工具页把写工具设成「要审」的服务仍保留在 `requireApproval` 里，升级后不会自动改回智能审查，需要到工具页把写工具改回「智能」并保存。

## 0.1.13

- 任务有了短序号（#1、#2…）并显示在消息里，号码在活跃任务之间复用，任务结束后回收。
- 微信可以直接文字回复「批准 / 拒绝 / 取消」，可带 #N 指定任务（全角＃和复制来的引号也认）；不带序号时由管家按待处理项核对。
- Telegram 消息加取消按钮，批准提示不再重复。

## 0.1.12

- 管家可以给 bot 改名：新增 rename_bot 工具，id 不变，改名不会打断正在跑的任务或唤醒时间。

## 0.1.11

- 修复重新部署后微信、Telegram 停摆几分钟：轮询改为每次 alarm 一次长轮询接力，Cron 改为一分钟一次、心跳 60 秒，断链一两分钟内自愈。
- 修复 codemode 报「Wasm code generation disallowed by embedder」：wasm 模块按 application/wasm 上传，不再被当成 Data 模块。

## 0.1.10

- 修复微信图片连续失败：解码器出错后自动重建，失败时会说明图片在哪一步被丢弃。

## 0.1.9

- 任务新增工具：读取当前时间、发起自定义 HTTP 请求（写操作需你批准）、读取产出文件，并可用 codemode 脚本组合多步操作。
- 侧栏的匿名统计开关收成一行，说明按需展开。

## 0.1.8

- 新增匿名使用统计：只上报心跳、功能使用、首次配置完成和已安装更新，可在侧栏开关里关闭（默认开启）。
- 界面文案精简：状态改用徽章、按钮不再重复标题、展开项统一叫「详情」。

## 0.1.7

- 启动与切页提速：本地启动判断、配置与状态磁盘缓存、页面间共享缓存。

## 0.1.6

- 客户端支持自动更新：后台检查新版本，弹窗确认后安装并重启。
