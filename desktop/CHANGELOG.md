# Changelog

## 0.1.9

- 任务新增工具：读取当前时间、发起自定义 HTTP 请求（写操作需你批准）、读取产出文件，并可用 codemode 脚本组合多步操作。
- 侧栏的匿名统计开关收成一行，说明按需展开。

## 0.1.8

- 新增匿名使用统计：只上报心跳、功能使用、首次配置完成和已安装更新，可在侧栏开关里关闭（默认开启）。
- 界面文案精简：状态改用徽章、按钮不再重复标题、展开项统一叫「详情」。

## 0.1.7

- 启动与切页提速：本地启动判断、配置与状态磁盘缓存、页面间共享缓存。

## 0.1.6

- 客户端支持自动更新：后台检查新版本，弹窗确认后安装并重启。
